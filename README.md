# ARCADIA 百科 · 部署与使用指南

纯静态网站，放在 GitHub Pages 上，不需要服务器。

| 页面 | 网址 | 给谁用 |
|---|---|---|
| 百科（读者看的） | `https://你的用户名.github.io/arcadia-wiki/` | 所有人 |
| 编辑器 | `https://你的用户名.github.io/arcadia-wiki/editor.html` | 只有你。必须用 GitHub 令牌登录 |

读者页面**完全不包含编辑功能**，也没有任何入口能进入编辑器。编辑器是另一个页面，登录时会检查令牌有没有这个仓库的写入权限。所以别人就算找到编辑器的网址，也进不去，更改不了网站。

```
arcadia-wiki/
├─ index.html            读者页
├─ editor.html           编辑器页
├─ assets/css/style.css  样式
├─ assets/js/            程序
├─ data/wiki.json        ★ 全部内容（中英文都在这里）
└─ images/               （可选）自己建，用来放图片
```

## 第一步：上传到 GitHub

1. 打开 github.com，登录你的账号（没有就先注册）。
2. 点右上角 **＋ → New repository**：
   - **Repository name** 填 `arcadia-wiki`。
   - 选 **Public**。免费账号只有公开仓库能开 GitHub Pages。
   - 点 **Create repository**。
3. 在新仓库页面点 **uploading an existing file**。
4. 把压缩包解开，把 `arcadia-wiki` 文件夹**里面的所有东西**拖进去。
   - 注意：拖的是里面的东西，不要连文件夹一起拖。
   - 必须保证仓库根目录直接就是 `index.html`、`editor.html`、`assets`、`data` 这几个。
5. 点 **Commit changes**。

## 第二步：打开 GitHub Pages

1. 仓库页面 → **Settings → Pages**。
2. **Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main` 和 `/ (root)`，点 **Save**。
4. 等 1～2 分钟，刷新这个设置页，上方会显示网址 `https://你的用户名.github.io/arcadia-wiki/`。

打开这个网址，能看到百科首页就成功了。右上角的 **中文 / EN** 可以切换语言。

## 第三步：生成编辑器用的令牌

1. GitHub 右上角头像 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**。
2. 按下面填写：
   - **Token name**：随意，例如 `arcadia-wiki-editor`。
   - **Expiration**：建议选一年，到期再重新生成。
   - **Repository access**：选 **Only select repositories**，只勾 `arcadia-wiki`。
   - **Permissions** → **Repository permissions** → **Contents**：选 **Read and write**。其他权限都不用动。
3. 点 **Generate token**，**马上复制**令牌（以 `github_pat_` 开头）。令牌只会显示这一次。

## 第四步：登录编辑器

1. 打开 `https://你的用户名.github.io/arcadia-wiki/editor.html`。
2. 用户名和仓库名会根据网址自动填好，你只需要把令牌粘贴进去，点 **登录**。
3. 同一台设备以后打开编辑器会自动登录。
4. 底部的 **退出登录** 会把这台设备上保存的令牌删掉。

> 令牌只保存在这台设备的浏览器里，不会写进网站。
> 不要把令牌发给别人，也不要截图外传。万一泄露，到 GitHub 生成令牌的那个页面把它删掉，再重新生成一个。

## 日常怎么编辑

编辑器会直接从 GitHub 仓库读取最新内容，不受网站部署延迟的影响。页面上蓝色的小按钮就是编辑功能：

- **首页**：新建模块（三种类型：百科页面 / 分类图鉴 / 时间线），编辑站点名称和阅读进度。
- **分类图鉴**（例如“人物”）：
  - **＋ 子界面**：新建分页，比如“人类 / 概念 / 特殊”。
  - **编辑这个子界面**：设置设定栏模板，每行写一个字段，格式是 `阶级 | Tier`。之后新建条目会自动带上这些字段。
- **条目页**：
  - **编辑基本信息**：标题、别名、导语、图片、剧透等级。
  - **编辑角色设定栏**：右侧信息框。每格上面填中文，下面填英文。
  - **添加章节**：左边写中文，右边写英文，下方都有实时预览。
- **时间线**：
  - **＋ 新建事件**：填“显示时间”和“排序值”，事件会自动排进时间线。
  - **编辑纪元**：设置纪元的范围和颜色。
  - **＋ 时间线**：再建一条新的时间线。

修改会**自动保存在本机**，然后：

1. 点 **👁 读者视角预览**，看读者会看到什么。顶部切换 EN 可以检查英文版。
2. 确认没问题后，点 **发布到网站**。
3. 等 1～2 分钟，读者就能看到了。

每次发布都会在 GitHub 留一条提交记录，可以随时找回旧版本。

### 中英双语

- 每个文字字段都有中文和英文两栏。
- 英文栏留空时，英文读者会看到中文原文，旁边有一个小小的「中」字标记。
- 编辑器里，所有缺英文的地方都会标出 **缺英文**，方便你慢慢补。
- 站内链接中英文都能用：中文正文写 `[[星晨]]`，英文正文写 `[[Starmorni]]`，都会指向同一个页面。前提是这个条目填了英文标题。

### 正文格式

| 写法 | 效果 |
|---|---|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `[[星晨]]` 或 `[[星晨\|主角]]` | 站内链接，按标题或别名自动查找页面 |
| `[文字](https://...)` | 外部链接 |
| `\|\|剧透内容\|\|` | 黑条遮住，点击才显示 |
| `- 项目` / `1. 项目` | 列表 |
| `> 引文` | 引用框 |
| `### 小标题` | 段落里的小标题 |

站内链接如果指向还不存在的页面，会显示成红色。在编辑器里点红色链接，可以直接创建那个页面。

### 防剧透

- **设置等级**：在“编辑站点信息”里设置阅读进度的各个等级，比如不剧透 / 读完第一篇 / 读完第二篇……
- **给内容标等级**：整个条目、单个章节、设定栏里的单个字段，都可以单独标剧透等级。
- **读者那边**：在顶部选择自己读到哪里，超出进度的内容会被遮住，点一下才显示。

### 图片

1. 在仓库里点 **Add file → Upload files**，上传图片时把文件名写成 `images/xxx.png`（这样会自动放进 `images` 文件夹）。
2. 在条目的“图片地址”里填 `images/xxx.png`。

## 以后想换成自己的域名

在仓库的 **Settings → Pages → Custom domain** 里填上域名，然后到域名商那里加 DNS 记录：

- 4 条 A 记录，指向 `185.199.108.153`、`185.199.109.153`、`185.199.110.153`、`185.199.111.153`。
- `www` 加一条 CNAME，指向 `你的用户名.github.io`。

详细步骤见 GitHub 官方文档《Managing a custom domain for your GitHub Pages site》。
